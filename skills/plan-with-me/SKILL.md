# Plan With Me

Use this when the student has an idea, assignment, feature request, or design decision but is unsure where to begin.

1. Ask one focused question at a time, and only when the answer cannot be found in the repository.
2. Help define the user-visible or technically observable outcome in one sentence.
3. Identify the relevant files, the existing pattern to follow, the constraints, and the smallest viable change.
4. Produce a short plan of steps. Each step states what the student will change and how they will check it.
5. Explain any design choice that materially affects complexity, compatibility, security, or maintainability. Favor the smallest design that meets the stated need.
6. Ask the student to pick the first step and attempt it.

Keep plans lightweight. Do not create planning files, formal work items, architecture documents, or implementation code unless the student explicitly asks.
